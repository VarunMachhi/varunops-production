How it works

Install once.
Manage from anywhere.

The agent checks in over HTTPS, reports inventory, receives only allow-listed app commands, and posts the result back to the server.

01

Enroll

Use a temporary enrollment token. The server returns a unique per-device credential, which is stored only as a hash server-side.

Windows PCVarunOps
02

Report

The agent sends heartbeat, hardware context and the versions of apps from your approved catalog.

03

Queue

Your browser writes commands to the server. Offline systems keep work queued until their next authenticated check-in.

InstallUpdateRemove
04

Verify

Results update the inventory and activity timeline, so you can distinguish queued, running, successful and failed work.

✓
Security built into the shape of the product

Powerful enough for IT.
Restricted enough to stay sane.

VarunOps does not expose an arbitrary command endpoint. Agent operations are constrained to server-approved applications and three explicit software actions.

See the architecture ›
01

Staff-only consoleDjango sessions, CSRF protection and staff authorization guard browser actions.

02

Per-device keysEach enrolled endpoint receives its own long random secret; the server keeps only a password hash.

03

Allow-listed commandsNo arbitrary PowerShell/CMD payloads are accepted through the device command API.

04

Production hardeningHTTPS redirect, secure cookies, HSTS options, CSP, clickjacking protection and rate limits are included.
