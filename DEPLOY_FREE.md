# VarunOps Free Test Deployment

## Recommended stack

- App: Render Free Web Service
- Database: existing Neon/Supabase PostgreSQL free tier
- Employee verification: Admin-delivered OTP (no email provider or domain required)

## Required Render environment variables

- `DATABASE_URL` = PostgreSQL connection string
- `ADMIN_EMAIL` = admin contact email (account metadata only)
- `ADMIN_PASSWORD` = strong admin password

`SECRET_KEY` and `AGENT_ENROLLMENT_TOKEN` may be generated by `render.yaml`.

## Employee onboarding

1. IT creates employee and receives a one-time temporary password.
2. Employee logs in with username + temporary password.
3. Employee connects the company PC and waits for the first verified agent sync.
4. Employee clicks **Request 6-digit OTP from IT**.
5. IT opens **Admin → Employees → Pending verification OTPs** and gives the displayed code to the correct employee.
6. Employee enters the OTP, creates a permanent password, and the dashboard unlocks.

OTP expires after 10 minutes. No email service, Resend account, SMTP server, or sending domain is required.

## Deploy update

Push the project to the same GitHub repository, then use **Render → Deploy latest commit**. Database migrations still run through the existing Render build/start flow.
